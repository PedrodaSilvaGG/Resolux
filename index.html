Como a pontuação funciona

Cada resposta recebe de 0 a 3 pontos. A nota de cada pilar é normalizada para uma escala de 0 a 100. O score geral é a média simples dos quatro pilares.

Plano orientativo

Escopo e interpretação do laudo

Este diagnóstico é uma ferramenta orientativa de autoavaliação, baseada exclusivamente nas respostas fornecidas. Não substitui auditoria técnica, análise jurídica, testes de segurança, inventário de ativos ou avaliação formal de conformidade com a LGPD. Antes de executar mudanças, valide requisitos, riscos, custos, contratos, criticidade dos sistemas e capacidade operacional.
